# Rock’n’Rostoll

## Pàgina estàtica

El projecte s'ha simplificat per funcionar només amb HTML, CSS i JavaScript natius.
Obre `index.html` des d'un navegador per visualitzar la pàgina principal i utilitza `about.html`, `contact.html`, `shop.html` i `avis-legal.html` per accedir a la resta de continguts.
