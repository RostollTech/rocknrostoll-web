# Rock’n’Rostoll

## Millores SEO aplicades

- Implementades metaetiquetes bàsiques (title, description, keywords, author, robots) i etiquetes socials (Open Graph i Twitter Cards) per millorar el fragment als cercadors i a les xarxes socials.
- Afegit script JSON-LD tipus `MusicEvent` amb informació clau sobre el festival per enriquir els resultats a Google.
- Creats els fitxers `sitemap.xml` i `robots.txt` a l'arrel del projecte per facilitar la indexació de totes les rutes principals.
- Garantit que totes les imatges tinguin atribut `alt` descriptiu i càrrega mandrosa (`loading="lazy"`) per millorar accessibilitat i rendiment.
- Enllaços interns actualitzats cap a les seccions principals (Home, About, Programa i Contacte) i reforçada la seguretat dels enllaços externs amb `rel="noopener noreferrer"`.

> Nota: Es recomana continuar optimitzant i exportant les imatges pesades a formats moderns (`.webp`, `.avif`) per mantenir un temps de càrrega baix.

## Pàgina estàtica

El projecte s'ha simplificat per funcionar només amb HTML, CSS i JavaScript natius.
Obre `index.html` des d'un navegador per visualitzar la pàgina principal i utilitza `about.html`, `contact.html`, `shop.html` i `avis-legal.html` per accedir a la resta de continguts.
